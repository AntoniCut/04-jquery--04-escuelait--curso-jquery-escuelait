Ejemplo 1 - hide() y show()

hide() · show()

Que hace este ejercicio

Practica selectores basicos de jQuery y controla la visibilidad de elementos con hide() y show(), ademas de crear contenido nuevo con $() y appendTo().

Objetivo: seleccionar por id/clase y animar ocultar / mostrar con hide() y show().

Selecciona por id y por clase con la funcion $().

hide() oculta el elemento y show() lo vuelve a mostrar.

El boton run dispara la animacion para ver el efecto en tiempo real.
