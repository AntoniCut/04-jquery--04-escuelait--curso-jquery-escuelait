Que hace este ejercicio

Usa each() para iterar sobre una coleccion de parrafos, contar los que tienen clase probando y listar su contenido.

Objetivo: dominar each() para operar sobre multiples elementos con $(this).

each() recorre cada elemento y ejecuta un callback.

Dentro del callback, $(this) es el elemento actual.

Puedes re-ejecutar, resaltar o resetear desde el select.
