Menú contextual

contextmenu · mousedown

Que hace este ejercicio

Este ejercicio reemplaza el menu contextual del navegador por uno personalizado y lo controla con eventos del raton en jQuery.

Objetivo: practicar eventos de raton y manejo de interfaz dinamica con jQuery.

contextmenu: evita el menu nativo y muestra el menu propio.

El menu se posiciona con coordenadas del click y se limita al viewport.

mousedown: detecta el boton pulsado, actualiza un mensaje y cierra el menu.
