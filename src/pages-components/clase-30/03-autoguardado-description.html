Fase 3

Como tercera fase se implementa la fase 2, más un mecanismo para que el formulario se envíe automáticamente cada cierto número de segundos. El plugin convierte un formulario normal en un formulario Ajax, con validación y además un mecanismo de autosave.

Al invocar al plugin se genera un temporizador para que el formulario se envíe por Ajax pasados unos segundos. El tiempo es configurable en el objeto de opciones, que recibe los mismos datos que la fase 2 más un dato llamado segundos. Por defecto segundos vale 20.

  1. Invocas al plugin y generas el temporizador para que se autoenvíe pasados esos segundos.
  2. Si pasados esos segundos no lo hemos enviado manualmente, el formulario se autoenvía y se establece otra vez el temporizador.
  3. Si antes de completarse los segundos el usuario envía el formulario con el botón, se envía por Ajax y el temporizador se para. Una vez recibida la respuesta, se vuelve a establecer.

El temporizador puede implementarse con setTimeout() o setInterval().

En esta página el autoguardado está a los 6 segundos y empieza activado. Si lo desmarcás, se cancela la espera. Si envías antes, esa espera se cancela y vuelve a contarse al terminar.
