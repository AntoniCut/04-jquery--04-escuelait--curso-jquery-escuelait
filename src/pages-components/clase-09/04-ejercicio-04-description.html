Ejercicio 04

each() · 1.6 + index * 0.25

Que hace este ejercicio

Practica la asignacion dinamica de estilos segun la posicion, creando una progresion visual de tamanos de texto crecientes con each() y una formula basada en el index.

Objetivo: usar operaciones matematicas con index para generar estilos progresivos.

Se itera cada parrafo y se calcula un tamano con 1.6 + index * 0.25.

Se asigna el tamano con css() en unidades rem.

Se antepone un span con el numero de parrafo y el tamano aplicado.
