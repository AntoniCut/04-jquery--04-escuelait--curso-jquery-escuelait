Que hace este ejercicio

Herramienta interactiva para probar selectores de jQuery en vivo. Elige un preset o escribe tu propio selector y aplica colores con css().

Objetivo: practicar selectores de forma exploratoria y ver como afectan al DOM al instante.

Usa el select de presets para cargar selectores tipicos.

Ajusta colores de fondo y texto desde los campos del panel.

Al cambiar el preset se aplica automaticamente sobre el playground.
