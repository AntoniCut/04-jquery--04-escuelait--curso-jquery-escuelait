Dimensiones - width(), height(), inner y outer

jQuery ofrece varios metodos para medir elementos segun si se quiere incluir solo el contenido o tambien padding, borde y margen.

Objetivo: distinguir que tipo de medida devuelve cada metodo para hacer calculos precisos.

width() y height() miden solo el contenido, sin padding ni borde.

innerWidth() e innerHeight() incluyen el padding del elemento.

outerWidth() y outerHeight() incluyen borde, y con true tambien el margin.
