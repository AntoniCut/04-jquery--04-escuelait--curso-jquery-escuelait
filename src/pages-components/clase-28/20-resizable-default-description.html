Funcionalidad por defecto

borde · asa · esquina

Que hace este ejercicio

Cualquier elemento puede cambiar de tamaño. Arrastra el borde derecho, el inferior o el asa de la esquina.

Objetivo: estirar la caja por el borde o por la esquina.

El asa aparece al activar resizable.

La caja parte de 12rem para que el cambio se note.
