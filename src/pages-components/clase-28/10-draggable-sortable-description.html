Draggable y Sortable

connectToSortable · clone

Que hace este ejercicio

Un elemento draggable puede soltarse dentro de una lista sortable y pasar a formar parte de ella.

Objetivo: arrastrar la pieza resaltada hasta la lista de abajo.

El elemento suelto se clona al entrar en la lista.

La lista se reordena y vuelve si el gesto no es válido.
