Incluir o excluir elementos

items · cancel

Que hace este ejercicio

items indica qué elementos se pueden ordenar. Los que quedan fuera tampoco sirven como destino. cancel impide arrastrarlos, pero siguen siendo un destino válido.

Objetivo: comparar la lista que excluye destinos con la que solo cancela el arrastre.

Arriba, los desactivados ni se mueven ni reciben a otros.

Abajo, no se arrastran, pero sí se puede soltar sobre ellos.
