Listas vacías

dropOnEmpty · tres listas

Que hace este ejercicio

Por defecto se puede soltar en una lista vacía. Con dropOnEmpty: false los elementos de la lista del centro no entran en la lista vacía.

Objetivo: vaciar una lista hacia la tercera y probarlo con la del centro.

La lista vacía reserva alto y muestra un texto.

La lista del centro no puede soltar en una lista vacía.
