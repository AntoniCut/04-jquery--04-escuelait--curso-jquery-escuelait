Hueco al soltar

placeholder · forcePlaceholderSize

Que hace este ejercicio

Al arrastrar, los demás dejan un hueco. placeholder le pone una clase a ese hueco para que se vea. forcePlaceholderSize le copia el tamaño del elemento.

Objetivo: arrastrar un elemento y ver el hueco resaltado.

El hueco usa ui-state-highlight.

El alto del hueco no se desploma al sacar el elemento.
