Conectar listas

connectWith · dos listas

Que hace este ejercicio

connectWith permite mover elementos de una lista a otra. Lo habitual es agrupar las listas con una clase y pasar esa clase.

Objetivo: pasar un elemento de la lista izquierda a la derecha.

Las dos listas comparten la clase de conexión.

En pantalla ancha quedan una al lado de la otra.
