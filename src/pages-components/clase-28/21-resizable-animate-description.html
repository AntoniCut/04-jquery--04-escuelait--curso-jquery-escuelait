animate · al soltar

Que hace este ejercicio

Con animate: true el elemento no sigue el borde mientras arrastras. Al soltar, anima hasta el tamaño del contorno.

Objetivo: soltar el asa y ver la caja llegar al tamaño nuevo.

Durante el gesto solo se ve el contorno.

Si el sistema pide menos movimiento, la animación dura cero.
