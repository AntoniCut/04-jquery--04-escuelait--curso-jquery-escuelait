Que hace este ejercicio

Reescribe el fontSizer de la clase 25 para que reciba un objeto de opciones. El destino a animar y el callback final dejan de estar fijos en el código del plugin.

Objetivo: sustituir los valores hardcodeados por settings obtenidos con $.extend({}, defaults, options).

Sin opciones, target vale #fontSizer y onFontResized es una función vacía.

Con opciones, target pasa a ser #divFontSizer y se ejecuta el callback.

$.when(...).done(...) espera a que termine la animación antes de llamar a onFontResized.

El callback se invoca con call para que this sea el elemento que dispara el plugin.
