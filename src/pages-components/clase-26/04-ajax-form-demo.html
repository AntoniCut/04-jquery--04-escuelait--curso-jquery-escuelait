Plugins ajaxForm y basicValidation

Los dos plugins se encadenan sobre el mismo formulario. Cada tarjeta cambia una opción para ver cómo se fusiona con los defaults.

Con valores por defecto

Sin opciones: usa action, method y data-ajaxform-target del formulario.

Solo target

El destino se indica en las opciones con target.

Con type GET

La opción type sobrescribe el method del formulario.

Con onSuccess

Callback con la respuesta cuando PHP devuelve ok: true.

Con onError

La opción url apunta a un archivo inexistente para forzar el fallo de Ajax.

Con onAlways

Se ejecuta al terminar la petición, vaya bien o mal.
