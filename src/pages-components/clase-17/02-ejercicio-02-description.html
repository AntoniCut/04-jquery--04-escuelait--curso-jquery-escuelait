#texto

Ejercicio 02

#texto · #salida

Que hace este ejercicio

Tienes un campo de texto (INPUT text) y un botón. Cuando pulsas el botón se genera un DIV y se inyecta en el DOM. El texto del DIV debe ser lo que haya escrito en ese momento en el campo de texto.

Objetivo: practicar la lectura de un input y la inyección dinámica de elementos en el DOM al enviar un formulario.

Al enviar el formulario se lee el valor del campo #texto.

Se crea un DIV con ese texto y se inserta en #salida.

Cada envío añade un nuevo bloque con el contenido escrito en ese momento.
