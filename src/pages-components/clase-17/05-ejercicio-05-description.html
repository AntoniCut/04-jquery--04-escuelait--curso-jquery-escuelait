Que hace este ejercicio

Tienes una lista de imágenes. Las imágenes tienen atributo "alt", con texto alternativo. Quieres crear pies de foto para cada una de las imágenes. El texto del pie de foto debe de ser el mismo que hay en el alt, el suyo de cada imagen. Haz un tratamiento por si la imagen no tiene atributo alt. En ese caso se debe mostrar un pie de foto con un texto genérico, por ejemplo "copyright 2026".

Objetivo: generar pies de foto a partir del atributo alt de cada imagen, con un fallback cuando no exista.

Se recorre cada imagen dentro de #destino.

Se crea un pie de foto con el texto del atributo alt.

Si no hay alt, se muestra un texto genérico de copyright.
