Plugins basicos

Cada tarjeta aplica un plugin. El ultimo bloque encadena varios.

urlize

Clic para ir a la URL de data-url.

Div convertido a enlace con el plugin urlize para acceder al curso de jQuery de Escuela IT de AntonyDev.

underlinize

Div con el plugin underlinize para aplicar subrayado.

boldize

Div con el plugin boldize para aplicar negrita.

fontSizer

Los botones animan el tamaño de fuente del destino.

Div con el plugin fontSizer para cambiar el tamaño de la fuente.

colorize

El input pinta el color del destino data-colorize-target.

Div con el plugin colorize para aplicar color.

Encadenando metodos

urlize + underlinize, boldize + colorize y fontSizer sobre #mydiv.
