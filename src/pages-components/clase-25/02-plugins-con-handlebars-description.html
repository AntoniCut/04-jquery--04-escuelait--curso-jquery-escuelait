Plugins con Handlebars

templatize · $.getJSON

Que hace este ejercicio

El plugin templatize lee un script type="text/x-handlebars-template", lo compila y sustituye el contenido del destino. El segundo argumento puede ser un objeto o una URL JSON.

Objetivo: encapsular Handlebars dentro de un plugin jQuery reutilizable.

$el.templatize("template", context) usa el objeto como contexto Handlebars.

Si el segundo argumento es un string, pide el JSON con $.getJSON.

El JSON vive en services/clase-25/template-data.json.
