Validación avanzada

regex · minlength · maxlength

Que hace este ejercicio

Los campos con clase .advanced-validation leen sus reglas de atributos data-advanced-validation-*: obligatorio, expresión regular, mínimo y máximo.

Objetivo: mostrar bajo el campo el primer mensaje que falle, sin enviar el formulario.

El nombre solo admite letras, entre 3 y 10 caracteres.

El teléfono solo admite dígitos, entre 9 y 15. El atributo data-advanced-validation lo marca como obligatorio.

validate devuelve una promesa: done si pasa y fail si hay errores.
