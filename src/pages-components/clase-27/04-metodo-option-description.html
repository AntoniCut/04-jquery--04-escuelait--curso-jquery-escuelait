option

Método option

getter · setter · message

Que hace este ejercicio

option lee o escribe una clave de las opciones de esa instancia. Cambiar message no reinicia el plugin: el siguiente error ya usa el texto nuevo.

Objetivo: leer el mensaje por defecto, sustituirlo y verlo al enviar un campo vacío.

Con dos argumentos lee: advancedValidation('option', 'message').

Con tres argumentos escribe y no devuelve la colección jQuery.

El setter comprueba !== undefined, así que también podría guardar false o una cadena vacía.
