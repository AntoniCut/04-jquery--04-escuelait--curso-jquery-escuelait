destroy

Método destroy

off · removeData · onDestroy

Que hace este ejercicio

destroy quita el listener de submit, borra los mensajes y elimina la instancia de $.data. Después el formulario se envía sin validar.

Objetivo: comparar un envío vacío antes y después de destruir el plugin.

Antes de destruir, un envío vacío se queda en la página y marca los campos.

onDestroy avisa cuando la instancia ya no existe.

El listener usa el namespace submit.advancedValidation para poder quitar solo el del plugin.
