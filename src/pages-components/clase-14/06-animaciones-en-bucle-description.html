Que hace este ejercicio

Este ejercicio crea una animacion en bucle para una capa que se desplaza, desaparece, reaparece y cuenta vueltas sin necesidad de recargar la pagina.

Objetivo: practicar bucles de animacion controlados y gestionar iniciar, pausar, reanudar y reiniciar una secuencia.

El ciclo se organiza por pasos para mover la capa de un extremo a otro, insertar esperas y actualizar el numero de vueltas completadas.

El boton Stop pausa la animacion en el punto actual y Animar la reanuda desde ese mismo paso.

El boton Reset limpia temporizadores, estado interno y estilos inline para volver al estado inicial del ejercicio.
