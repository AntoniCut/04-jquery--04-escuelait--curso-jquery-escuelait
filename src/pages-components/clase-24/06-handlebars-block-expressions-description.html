Que hace este ejercicio

Registra dos helpers personalizados: toH1 envuelve el titulo en un h1 y toUl recorre un array y pinta una lista.

Objetivo: extender Handlebars con registerHelper y expresiones de bloque.

{{toH1 title}} es un helper simple: recibe un valor y devuelve HTML seguro.

{{#toUl people}}...{{/toUl}} es un helper de bloque: usa options.fn(item).

Hay dos previews: uno para el titulo/cuerpo y otro para la lista de personas.
