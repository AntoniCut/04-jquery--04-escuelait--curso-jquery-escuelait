Que hace este ejercicio

El contexto incluye un objeto anidado author. El template lee {{author.id}} y {{author.name}} con la notacion de path.

Objetivo: acceder a propiedades anidadas sin aplanar el modelo de datos.

El contexto monta author: { id, name } a partir de los inputs.

Handlebars resuelve el path con puntos: {{author.name}}.

Si un campo va vacio, se usa un valor por defecto para que el template no quede en blanco.
