UI

Usando jQuery UI

widgets · demos · tema

Que se hace en esta clase

Widgets de jQuery UI. Cada grupo recoge las demos de jqueryui.com: acordeón, autocompletado, botones, calendario, diálogos, menús, pestañas y el resto de controles.

Objetivo: abrir cada demo y probar el widget.

01. Accordion

01. Funcionalidad por defecto

Pulsa una cabecera para abrir su panel y cerrar el que estaba abierto. El marcado es una serie de títulos y bloques, así que el texto se puede leer sin JavaScript.

Ir a la demo

02. Contraer el contenido

Con <code>collapsible</code> se puede cerrar también el panel abierto. El acordeón puede quedar del todo plegado.

Ir a la demo

03. Iconos personalizados

La opción <code>icons</code> cambia el icono de la cabecera cerrada y el de la cabecera activa.

Ir a la demo

04. Rellenar el espacio

<code>heightStyle: "fill"</code> reparte la altura del marco entre la cabecera y el panel abierto. Al cambiar el tamaño del marco, <code>refresh</code> vuelve a calcular esa altura.

Ir a la demo

05. Sin altura automática

Con <code>heightStyle: "content"</code> cada panel mide según su texto. Los paneles cortos no estiran un hueco vacío.

Ir a la demo

06. Ordenable

Las cabeceras se arrastran para cambiar el orden de los paneles. Al soltar, el acordeón se actualiza.

Ir a la demo

02. Autocomplete

01. Funcionalidad por defecto

Escribe <code>ja</code>. Aparecen Java y JavaScript. Con <code>jq</code> aparece JQuery y con <code>py</code> aparece Python.

Ir a la demo

02. Ignorar acentos

Escribe el nombre sin acento. <code>alvaro</code> encuentra Álvaro, <code>maria</code> encuentra María y <code>inigo</code> encuentra Íñigo.

Ir a la demo

03. Categorías

Escribe en el campo. Con <code>j</code> salen Java y JavaScript bajo Lenguajes, y jQuery y jQuery UI bajo Librerías. Las cabeceras no se eligen: el teclado las salta.

Ir a la demo

04. Lista combinada

Escribe <code>py</code> para elegir Python, o <code>ja</code> para ver Java y JavaScript. El botón pegado al campo abre la lista entera. <code>Mostrar el select</code> enseña la lista original. Si el texto no coincide, el campo se vacía.

Ir a la demo

05. Datos y presentación propios

Escribe <code>jq</code>. Salen jQuery, con «Escribe menos y haz más», y jQuery UI, con «Interacciones, widgets y efectos». El campo se queda con el nombre.

Ir a la demo

06. Varios valores

Escribe <code>ja</code> y elige Java. El campo queda <code>Java, </code>. Sigue con <code>py</code> para añadir Python.

Ir a la demo

07. Varios valores en remoto

Hacen falta dos letras. Escribe <code>mad</code>, elige Madrid y, tras la coma, escribe <code>bar</code> para añadir Barcelona. La lista tarda un momento.

Ir a la demo

08. Origen remoto

Hacen falta dos letras. Escribe <code>mad</code> y, tras un momento, sale Madrid. Con <code>va</code> salen Valencia y Valladolid.

Ir a la demo

09. Origen remoto JSONP

Hacen falta dos letras. Escribe <code>mad</code>. El aviso pasa a «Pidiendo datos…» y, al cabo de un momento, sale Madrid.

Ir a la demo

10. Origen remoto con caché

Hacen falta dos letras. Escribe <code>vi</code>: la primera vez espera y guarda el resultado. Borra el campo y vuelve a escribir <code>vi</code>. El aviso dice que la lista sale de la caché.

Ir a la demo

11. Resultados con desplazamiento

Escribe <code>a</code>. Hay varias coincidencias y el menú solo muestra unas pocas: el resto se ve al desplazar la lista.

Ir a la demo

12. XML leído una vez

Escribe <code>py</code> y sale Python. Con <code>ja</code> salen Java y JavaScript. Esas etiquetas se leyeron del XML al cargar la página.
