Template systems

compile · each · path

Que se hace en esta clase

Genera HTML a partir de plantillas Handlebars y, en contraste, monta el mismo resultado creando nodos con jQuery.

Objetivo: separar datos y markup, y saber cuando basta con generar el DOM a mano.

Handlebars.compile transforma un string o un script en funcion.

El template puede vivir en JS, en el HTML o llegar por Ajax.

Paths, #if, #each y helpers de bloque pintan listas.
