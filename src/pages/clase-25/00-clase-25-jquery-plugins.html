Que se hace en esta clase

Extiende $.fn para crear plugins reutilizables, encadenarlos y, en la segunda demo, conectar un plugin con Handlebars.

Objetivo: devolver this.each(...) para poder encadenar metodos.

El patron es $.fn.nombre = function () {}.

urlize, boldize y colorize se encadenan sobre la coleccion.

templatize compila Handlebars y pinta un objeto o un JSON.

Dos practicas: plugins basicos y plugin con plantilla.
