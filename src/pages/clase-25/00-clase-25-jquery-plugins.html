Clase 25 - jQuery Plugins

Que hace esta clase

Esta pagina resume los ejercicios de la clase 25: como extender $.fn para crear plugins reutilizables, encadenarlos y, en el segundo ejercicio, conectar un plugin con Handlebars.

  • 01 Plugins basicos: urlize, underlinize, boldize, fontSizer y colorize, aplicados uno a uno y encadenados.
  • 02 Plugin templatize: compila un template Handlebars y pinta el HTML con un objeto o con un JSON cargado por URL.

Objetivo: entender el patron $.fn.nombre = function () { return this.each(...) } y devolver la coleccion para poder encadenar metodos.
