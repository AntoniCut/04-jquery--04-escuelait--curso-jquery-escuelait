html()

Manipulación básica

html · attr · data · each

Que se hace en esta clase

Enseña a leer y escribir el contenido de los elementos con html() y text(), a distinguir atributos de propiedades con attr() y prop(), a guardar datos en el DOM con data() y a recorrer colecciones con each().

Objetivo: manipular contenido, atributos y datos de elementos del DOM con los metodos basicos de jQuery.

html() interpreta etiquetas y text() trata todo como texto plano.

attr() lee el HTML y prop() lee el estado real del DOM.

data() guarda valores y each() recorre cada elemento.
