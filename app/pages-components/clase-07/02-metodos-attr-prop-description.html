Que hace este ejercicio

Trabaja con attr() y prop() para leer y modificar atributos HTML y propiedades del DOM en un formulario real.

Objetivo: distinguir atributos y propiedades y saber cual usar en cada caso.

attr() lee atributos como action o placeholder.

prop() gestiona estados como checked.

El checkbox muestra/oculta el bloque avanzado; el select permite inspeccionar y resetear.
