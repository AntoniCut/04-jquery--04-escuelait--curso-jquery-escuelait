Que hace este ejercicio

El plugin hilight resalta cada elemento: aplica color de texto, color de fondo y envuelve el contenido en <strong>. Los cinco casos pasan un subconjunto distinto de opciones.

Objetivo: ver que las opciones no indicadas se rellenan con los defaults y que estos se pueden exponer fuera del plugin.

Los defaults viven fuera de $.fn.hilight, así que se declaran una sola vez.

Si solo se pasa foreground, el background sigue siendo el del default.

onFormatted se llama con call(this), así que el callback accede al elemento ya resaltado.

$.extend($.fn.hilight, { defaults }) publica los defaults para poder consultarlos o cambiarlos desde fuera.
