Que hace este ejercicio

Aplica cinco plugins escritos sobre $.fn a elementos concretos: convertir un bloque en enlace (urlize), subrayar, poner en negrita, cambiar el tamaño de fuente y pintar el color.

Objetivo: ver el ciclo each → efecto → return this para poder encadenar plugins.

urlize lee data-url y redirige al hacer clic.

fontSizer anima font-size del destino indicado en data-fontsizer-target.

El bloque combinado encadena .urlize().underlinize() y .boldize().colorize().
