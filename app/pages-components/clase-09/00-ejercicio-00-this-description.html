Que hace este ejercicio

Pone en practica el concepto de this, fundamental para trabajar con eventos y manipular el elemento sobre el cual se dispara una accion. Dentro de each(), this apunta al elemento actual de la iteracion.

Objetivo: dominar this y $(this) en jQuery para manejar iteraciones de forma precisa y eficiente.

this dentro de each() es el elemento nativo del DOM en cada vuelta.

$(this) / $(elem) lo convierten a objeto jQuery para usar metodos de la libreria.

Se recorre #lista li, se renumera el texto y se colorea segun el indice par/impar.
