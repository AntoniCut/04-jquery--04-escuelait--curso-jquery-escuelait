Ejercicio 03

% · index % array.length

Que hace este ejercicio

Extiende el ejercicio anterior al manejar el caso en que hay mas elementos que colores en el array, reciclando el patron con el operador % (modulo).

Objetivo: aplicar el operador modulo para reciclar patrones en iteraciones.

Se usa index % array.length para obtener un indice siempre valido.

Asi el color vuelve al principio cuando se acaban los valores del array.

Es una practica comun para ciclos y patrones repetitivos con datos limitados.
