Que hace este ejercicio

Variante del select combinado que usa dataType: "jsonp". El servidor envuelve el JSON en un callback, lo que permite peticiones cross-domain tipicas del patron JSONP.

Objetivo: Diferenciar JSON vs JSONP en $.ajax() y entender el parametro callback que genera jQuery.

La peticion usa dataType: "jsonp" en lugar de "json".

El PHP detecta $_GET["callback"] y responde como script.

El resto del flujo (beforeSend, success, complete, error) se mantiene igual.
