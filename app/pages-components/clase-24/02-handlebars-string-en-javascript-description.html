Que hace este ejercicio

El template vive en un string de JavaScript con {{ title }} y {{ body }}. Al generar, se leen los inputs y se pasan como contexto a Handlebars.

Objetivo: interpolar datos de formulario en un template definido en codigo.

Los placeholders {{title}} y {{body}} se sustituyen por los valores de los inputs.

El contexto se arma en el momento del click, no al cargar la pagina.

El HTML generado se pinta en el preview y se copia al textarea para ver el markup.
