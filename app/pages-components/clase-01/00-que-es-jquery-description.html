Que hace este modulo

Introduce jQuery, la libreria JavaScript mas usada para simplificar la manipulacion del DOM, el manejo de eventos y las peticiones AJAX.

Objetivo: entender que es jQuery, por que se usa y en que situaciones sigue siendo util hoy en dia.

jQuery es una libreria, no un framework: se include y ofrece utilidades listas.

Abstrae diferencias entre navegadores y reduce el codigo necesario para el DOM.

Permite AJAX, animaciones y plugins de forma sencilla.
