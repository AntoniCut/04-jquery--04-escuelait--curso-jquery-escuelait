init · $.extend · submit

Que hace este ejercicio

El formulario se inicializa sin opciones. advancedValidation() fusiona los defaults y, al enviar, valida los campos con data-basic-validation-required.

Objetivo: ver que el comentario no se exige porque no lleva el data attribute.

$.extend({}, defaults, options) crea un objeto nuevo y no muta los defaults del plugin.

Si la validación pasa, el plugin llama al submit nativo y el navegador abre enviar.php.

Si falta un campo obligatorio, el envío se cancela y aparece el mensaje bajo el input.
