hook()

Hooks

onInit · onValidating · onValidated

Que hace este ejercicio

Los hooks no son eventos de jQuery. Son funciones guardadas en las opciones y el plugin las llama con this apuntando al formulario.

Objetivo: leer el orden onInit, onValidating, onIsValid o onIsNotValid, y onValidated.

onInit se dispara al crear la instancia, antes de pulsar Validar.

validate encadena la promesa con done, fail y always.

El formulario se queda en la página para poder leer los tres mensajes.
