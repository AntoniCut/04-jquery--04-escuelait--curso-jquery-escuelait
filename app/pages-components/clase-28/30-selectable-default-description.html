Que hace este ejercicio

Dibuja un recuadro con el cursor para seleccionar varios elementos. Con Ctrl, o Cmd, sumas elementos que no están juntos.

Objetivo: marcar un grupo y luego sumar otro con Ctrl.

Un clic marca un elemento.

El recuadro marca todos los que toca.
