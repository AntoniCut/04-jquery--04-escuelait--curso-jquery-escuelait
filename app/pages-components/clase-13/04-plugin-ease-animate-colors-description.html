Que hace este ejercicio

Este ejercicio combina jQuery Easing con el plugin Animate Colors para animar tamaño y colores en una sola transicion.

Objetivo: practicar animaciones enriquecidas mezclando easing y cambios de color en jQuery.

Se toma un easing del selector y se usa para controlar la curva de la animacion.

Se animan propiedades de dimensiones (width, height) y de color (backgroundColor, color).

Al finalizar, se recuperan los estilos originales para mantener un ciclo de prueba limpio.
