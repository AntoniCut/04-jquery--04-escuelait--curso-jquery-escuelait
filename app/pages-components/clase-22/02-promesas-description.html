Que hace este ejercicio

$.get devuelve una promesa. Aqui se cargan fragments HTML (_partial-01.html y _partial-02.html) de tres formas: callback clasico, .done() y $.when() con una o varias peticiones.

Objetivo: pasar del callback de $.get a encadenar .done() / .fail() y a esperar varias peticiones a la vez con $.when().

El primer boton combina callback, .done() y los tres argumentos de $.get.

$.when($.get(...)) envuelve una sola peticion en una promesa.

Con varias peticiones, cada argumento de .done() es el retorno de un $.get.
