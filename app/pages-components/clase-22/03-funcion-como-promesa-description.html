esPar(n)

Función como Promesa

esPar(n) · $.Deferred()

Que hace este ejercicio

esPar(n) crea un $.Deferred() interno y devuelve solo la promesa con .promise(). Si el valor es par se resuelve; si es impar o no es un numero, se rechaza.

Objetivo: encapsular logica sincrona (o asincrona) detras de una API de promesa, sin exponer resolve / reject al codigo que la consume.

El consumidor solo ve .done() y .fail(), no el Deferred.

Un numero par muestra ¡¡Es par!!; uno impar muestra Mal!!!.

Si el valor no es numerico, la promesa se rechaza con un mensaje de error.
